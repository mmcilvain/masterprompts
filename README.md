# Master Prompts

This repository stores concise, reusable prompts for common business and personal tasks.

Use the sections below to quickly find the right prompt.

| Category | Prompt | Use it when you need to... |
|---|---|---|
| Analytics | [Data Analysis Quality Audit](prompts/analytics/data-analysis-quality-audit.md) | Analyze a dataset carefully, check quality issues, separate facts from assumptions, and produce decision-ready findings. |

## How to Use a Prompt

1. Open the prompt that best matches your task.
2. Copy the full prompt into your AI assistant.
3. Replace the bracketed placeholders with your notes, context, data, or examples.
4. Add any extra constraints, preferred tone, or output format you want.

## Naming Convention

Prompt files use descriptive, hyphenated names so they are easy to scan in the library, for example:

- `jira-ticket-master-prompt.md`
- `data-analysis-quality-audit.md`
- `news-analysis-source-audit.md`
